# 薬機法・景表法ルール【必ず守る】

よもぎ蒸しサロンは**医療機関ではありません**。
そのため、記事の中で「病気が治る」「症状が改善する」といった表現を使うことは
薬機法（医薬品医療機器等法）で禁じられています。景品表示法（優良誤認）にも関わります。

**このルールは、筆者ルール・記事構成・文字数指定よりも優先されます。**
表現に迷ったら、必ず弱いほう（断定しないほう）を選んでください。

---

## 2. 言い換え表（OK）

| 書きたいこと | ✗ NG | ○ OK |
| --- | --- | --- |
| 温まる | 冷え性が改善します | 体の芯からじんわり温まる時間です |
| 汗 | デトックスで毒素が出ます | 気持ちのいい汗をかいていただけます |
| 生理まわり | 生理痛が軽くなります | 生理前の過ごし方を見直すきっかけにされる方が多いです |
| 妊活 | 妊娠しやすくなります | 妊活中の方にも多くご来店いただいています |

| リラックス | 自律神経が整います | ひとりで静かに過ごせる時間です |
| 体質 | 体質が変わります | ご自身の体の変化に気づきやすくなります |
| 継続 | 通えば必ず変わります | 続けてご来店くださる方が多いです |

## 3. 使ってよい書き方の型

効果を言いたくなったら、次の3つの型のどれかに置き換えます。

1. **体験の描写**：「15分ほどで、背中からじんわり汗がにじんできます」
2. **感想としての伝聞**：「『体が軽い気がする』とおっしゃる方がいます（※個人の感想です）」
3. **時間・場所の価値**：「スマホを置いて、誰にも邪魔されない40分です」

---

## 4. お客様の声を載せるとき

- 必ず **※個人の感想です** を声のすぐ後ろに入れる
- 感想であって、効果の保証ではないと分かる書き方にする
- 病名・治療の経過を語る内容は載せない
- 「〜が治りました」という声は、そのままでは載せない（掲載する側の責任になります）

## 5. 体調・通院中の方への配慮（必ず入れる）

次のいずれかに当てはまる方に向けては、記事内に一言必ず添えてください。

- 妊娠中の方／妊娠の可能性がある方
- 通院中・投薬中の方
- 手術後の方

添える文の例：

> ご妊娠中の方、通院中の方は、念のためかかりつけの先生にご相談のうえお越しください。

---

## 6. 書き終わったあとのセルフチェック

1. 「治る」「改善」「効果」「効く」「解消」で本文を検索して、1つも残っていないか
2. 病名が「これに効く」という文脈で使われていないか
3. お客様の声すべてに「※個人の感想です」が付いているか
4. 「絶対」「必ず」「100%」を使っていないか
5. 根拠のない数字（〇割の女性が…）を書いていないか
6. 妊娠中・通院中の方への一言が入っているか

**1つでも引っかかったら、書き直してから保存します。**
