# 記事構成：季節のご案内・キャンペーン（短文）

季節の切り替わりや、期間限定メニューのお知らせ用。
1200〜1800字程度の短い記事です。売り込みの色を出しすぎないのがコツです。

## 1. リード文（見出しなし・100〜150字）

- 季節の景色・空気の変化を一場面で書く
- そこに体の変化を重ねる（「朝、布団から出るのがつらくなってきました」）

## 2. ●この季節に多いご相談（300〜400字）

- その季節に実際に増える相談を2〜3つ
- 日常の言葉で。断定せず「〜という方が増えます」

## 3. ●この時期のおすすめの過ごし方（300〜400字）

- サロンの宣伝ではなく、家でできることを先に書く（湯船・靴下・飲み物・寝る前の5分）
- 読者がその場でできることを1つは必ず入れる

## 4. ●サロンからのご案内（300〜400字）

- 期間・内容・料金・予約方法をはっきり書く（あいまいにしない）
- 数量や期間の限定はある場合だけ書く。無い限定を作らない
- 効果の断定はしない（薬機法ルール.md）

## 5. ●ご予約はこちら（100〜200字）

- config.json の `salon.reserve_url` / `salon.name` / `salon.area` を使って導線を置く
- 「よかったら」「気が向いたら」の温度で締める

---

## 書くときのチェック

1. 期間・料金・条件を書き漏らしていないか
2. 「今だけ」「絶対」などの煽りになっていないか
3. 効果・効能の断定が無いか
4. 予約URLが入っているか
