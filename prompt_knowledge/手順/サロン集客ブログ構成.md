# 記事構成：サロン集客ブログ（標準）

よもぎ蒸しサロンのブログ記事の標準構成です。
検索から来た「まだサロンを知らない人」が、読み終わったときに
「ここなら行ってみたいかも」と思える流れにします。

書き出す前に、次の3つを自分の中で決めてから書き始めてください。

- **誰に**：どんな人が、どんなときに検索してこの記事にたどり着くか
- **どの悩み**：その人がいま一番つらいこと（1つに絞る）
- **どこへ**：読み終わったあとにしてほしい行動（ご予約／まず知ってもらう）

---

## 1. リード文（見出しなし・150〜250字）

- 読者の状況を一場面だけ具体的に描く（時間帯・場所・体の感じ）
- 「私も同じでした」と一言だけ寄り添う
- この記事で何がわかるかを1文で示す
- ここでは売り込まない

## 2. ●悩みの具体化（400〜600字）

- 読者が「それ、私のことだ」と思う場面を3つほど並べる
- 病名で語らず、**日常の言葉**で書く（「生理痛がひどい」→「予定を入れるのが怖い日がある」）
- まわりに相談しづらい気持ちにも触れる

## 3. ●なぜそうなるのか（400〜600字）

- 体のしくみをやさしく説明する（専門用語は出したらその場で言い換える）
- 断定しない。「〜と言われています」「〜な方が多いようです」
- 原因を1つに決めつけない（生活・季節・体質など複数の見方を示す）

## 4. ●よもぎ蒸しはどんな時間か（500〜700字）

- **効能ではなく「体験」を書く**（薬機法ルール.md を厳守）
- 当日の流れを順番に：着替え → 座る → 温まる → 汗 → 休憩 → 水分
- 五感の描写を入れる（よもぎの香り、じんわりする感じ、静かな時間）
- 所要時間・服装・持ち物など、初めての人が不安になる点を先回りして書く

## 5. ●サロンでよくいただくご相談（400〜600字）

- 実際のご相談・お客様の声を2〜3件（※個人の感想です を必ず添える）
- 「こうおっしゃる方が多いです」という形にする
- ここでも効果の断定はしない

## 6. ●初めての方によくあるご質問（300〜500字）

- Q&A形式で3〜5個
- 定番：生理中は入れますか／妊娠中は／何回くらい通えば／予約なしでも／持ち物は
- 体調・通院中の方には「かかりつけの先生にご相談ください」を添える

## 7. ●まとめ／ご案内（200〜300字）

- 記事の要点を3行でまとめる
- 「がんばりましょう」ではなく「自分を後回しにしなくていいですよ」の温度で締める
- 最後に**ご予約・お問い合わせの導線**を置く
  - config.json の `salon.reserve_url` と `salon.name` を読み、次の形で入れる

```
●ご予約・ご相談はこちら

{サロン名}（{エリア}）
ご予約・詳細はこちらからご覧いただけます。
{予約URL}
```

---

## 書くときのチェック

1. 効果・効能の断定が1つも無いか（薬機法ルール.md）
2. お客様の声に「※個人の感想です」が付いているか
3. 不安をあおる表現になっていないか
4. 見出しは4〜6本、「●」で統一されているか
5. 最後に予約導線（URL）が入っているか
6. 体験の具体描写（五感）が3か所以上あるか
