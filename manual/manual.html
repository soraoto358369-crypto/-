1. このアプリについて

サロンのブログ記事を、ブラウザの画面でボタンを押すだけでつくれるツールです。テーマを選ぶと、あなたのサロンの言葉で記事が書かれ、パソコンの中に保存されます。

書き上がった記事は 自動では投稿しません。内容を確認してから、ご自身でブログ・UTAGE・SNS に貼り付けてお使いください。「気づいたら変な記事が公開されていた」ということが起きない作りにしています。

テーマ指定 / 一覧 / メモ
→
記事生成サロンの声で
→
保存articles/
→
コピーして貼るご自身で確認
操作はすべて画面のボタン or チャット欄から。コマンドを打つ必要はありません。

2. 初回セットアップ（はじめに）

最初の1回だけ、次の準備をします。2回目からは start_webapp.bat をダブルクリックするだけです。

1

Python を入れる

python.org からインストールします。インストール画面の 「Add python.exe to PATH」にチェックを入れてください（ここが抜けると起動しません）。

2

claude CLI を入れる

Node.js を入れたうえで、コマンドプロンプトで次を実行します。

npm install -g @anthropic-ai/claude-code
3

アプリを起動する

start_webapp.bat をダブルクリック。ブラウザが自動で開きます（http://127.0.0.1:8788）。

4

サロン情報を登録する

左の 🏠「サロン情報を登録・編集」 を押して、サロン名・エリア・営業時間・ご予約ページのURL・メニューを入れて保存します。

ここで入れた内容が、記事の最後の「●ご予約・ご相談はこちら」に自動で入ります。

サロン名とご予約URLが未設定だと、記事の最後の案内が空欄になります。最初に必ず登録してください。

4. 記事をつくる（4つの方法）

① テーマ指定で1件

左の [1] を押すと「どんなテーマにしますか？」と聞かれます。答えると、そのまま1記事書いて articles/ に保存します。

② テーマ案を20個つくる

左の [2]。お客様からよく聞かれることや季節の相談をもとに、ブログのテーマ案を20個作って一覧（themes.json）に貯めます。

テーマに迷ったら、まず [2] で貯めてから [3] でまとめて書くのが楽です。

③ 複数件まとめて生成

左の [3]。貯まっているテーマが一覧で出るので、書きたいものにチェックを入れて「📝 選択を生成」。選んだ分を続けて書いて保存します。

④ Obsidian のメモから

左の [5]。Obsidian のフォルダを指定すると、その中のメモ（.md）を元に記事を書きます。施術中に気づいたことをメモしておくと、そのまま記事になります。

文字数を決めたいとき

ヘッダーの 「文字数」 で目標を選びます。選んだ字数は、筆者ルールの既定より優先されます。

5. 薬機法のルール（いちばん大事）

よもぎ蒸しサロンは医療機関ではありません。「治る」「改善する」「効果があります」と書くと、薬機法（医薬品医療機器等法）違反になります。

このシステムは記事を書く前に必ず prompt_knowledge/薬機法ルール.md を読み、NG表現を避けて書きます。書き終えたあとにもセルフチェックをします。

✗ 書いてはいけない○ こう書く
冷え性が改善します体の芯からじんわり温まる時間です
生理痛が治ります生理前の過ごし方を見直すきっかけにされる方が多いです
デトックスで毒素が出ます気持ちのいい汗をかいていただけます
妊娠しやすくなります妊活中の方にも多くご来店いただいています
不眠が治ります「その日はよく眠れた」とおっしゃる方がいます（※個人の感想です）

ルールの中身は左の ⚖「薬機法ルールを確認・編集」 から見られます。表現を足したいときはここに書き足してください。

生成された記事は、公開前に必ずご自身の目で確認してください。最終的な責任はサロン側にあります。

6. ナレッジ（文体・構成の管理と切替）

「どんな声で書くか」と「どんな流れで書くか」は、それぞれファイルで管理しています。

種類中身場所
🎭 筆者ルール文体・口調・人柄（誰が書いているか）prompt_knowledge/筆者/
📝 記事構成記事の流れ（集客ブログ／季節のご案内）prompt_knowledge/手順/
⚖ 薬機法ルール使ってはいけない表現と言い換えprompt_knowledge/薬機法ルール.md
📐 整形ルール改行・空行・句読点の決まりprompt_knowledge/整形ルール.md
🏷 よく使うワード記事に自然に混ぜたい言い回しprompt_knowledge/ワード/

筆者ルールと記事構成は複数持てます。ヘッダーのドロップダウンで「今どれを使うか」を切り替えられます（季節のお知らせを書くときだけ構成を変える、といった使い方ができます）。

自分の文章を覚えさせる

左の 🧠「過去記事から筆者ルール学習」 に、これまで書いたブログや Instagram の文章を貼り付けると、その文体を分析して新しい筆者ルールを作ります。

7. 右パネル（テーマ・記事の管理）

  • 環境ステータス：Python・claude CLI・サロン名・ご予約URL・使用中のナレッジが一目でわかります
  • テーマ：未着手の一覧。クリックするとそのテーマで記事を書きます。チェックして🗑で削除もできます
  • 記事：未公開／公開済みの一覧。クリックするとその場で本文を直せます

8. 記事を貼り付けて公開する

1

内容を確認する

右パネルの記事をクリックして、本文を読みます。直したいところはその場で編集して保存できます。

2

📋 で貼り付け用テキストを出す

記事の右にある 📋 を押すと、改行と余白を整えたテキストが出ます。「📋 コピー」でコピーして、ブログ・UTAGE・Instagram に貼り付けてください。

余白の量や折返しの幅は、左の ⚙「貼り付けの余白設定」 で調整できます。

3

✅ 公開済みにする

公開が済んだ記事はチェックを入れて 「✅ 公開済みに」。articles/published/ に移動して、未公開の一覧がすっきりします。

9. 仕組みとデータ

アプリは、あなたのパソコンの中だけで動きます（ローカルサーバー）。画面で押したボタンは、claude CLI への指示に変換されて実行されます。

ファイル役割
CLAUDE.mdclaude への指示書。記事の書き方・保存先のルール
config.jsonサロン情報・ご予約URL・貼り付けの余白設定
themes.jsonテーマの一覧（pending＝未着手 / done＝完了）
articles/書けた記事。published/ は公開済み
article_formatter.py貼り付け用に改行・余白を整えるプログラム

10. 困ったときは

症状対処
ブラウザが「接続が拒否されました」黒いウィンドウ（サーバー）が閉じていないか確認。start_webapp.bat を再実行
「claude CLI が見つかりません」npm install -g @anthropic-ai/claude-code を実行。それでも出るならパソコンを再起動
Python が無いと言われるインストール時に「Add python.exe to PATH」を入れて入れ直す
記事の最後の予約案内が空🏠「サロン情報」でサロン名とご予約URLを登録
記事が短いヘッダーの「文字数」で目標を指定してから生成する
原因がわからない診断.bat をダブルクリックし、出てきた「診断結果.txt」の中身を相談相手に渡す
