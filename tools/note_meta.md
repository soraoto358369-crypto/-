# note投稿用メタ情報 一覧

各記事のファイル末尾（`【終了】`以降）にも同じ内容があります。
`【終了】`以降は `note_poster.py` が本文から除外するので、投稿されません。

## 投稿時の使い方

1. **タイトル** … 記事の第1見出し（●）が自動でタイトルになります
2. **ハッシュタグ** … note の「ハッシュタグ」欄に貼り付けます
3. **説明文** … note の「記事の説明」欄、またはSNSシェア時の文に使います

※ `note_poster.py` にハッシュタグの自動入力機能はありません。手動で貼り付けてください。
