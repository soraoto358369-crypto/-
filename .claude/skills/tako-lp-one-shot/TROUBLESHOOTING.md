# 困った時 — 買った人が実際に詰まるところ

先に結論だけ。右の列を順にやれば直ります。

## 始める前

| 困りごと | 直し方 |
| --- | --- |
| Claude Code が入っていない | https://claude.com/claude-code の手順で。Pro 以上のプランが必要。このスキルは Claude Code の中で動く |
| `.claude` フォルダが見つからない | 隠しフォルダ。Windows はエクスプローラーの「表示 → 隠しファイル」、Mac は Finder で `Cmd+Shift+.`。もしくはアドレス欄に `%USERPROFILE%\.claude\skills`（Win）/ `~/.claude/skills`（Mac）を貼る |
| 「スタート」と打っても別のスキルが反応する | 他の LP 系スキルと言葉が重なることがある。`/tako-lp-one-shot` と打つか、「たこLP」と打つ |
| `python` と打つと Microsoft Store が開く（Windows） | Store 版の空コマンド。https://www.python.org/ から入れて、インストール時に「Add to PATH」にチェック。または `py -3` を使う |
| Pillow / Node / HyperFrames が無いと言われる | チャットに「セットアップ」と打つ。スキルが全部入れる（ターミナル不要）。それでも `[NG ]` なら、案内された公式ページのインストーラーを実行してもう一度「セットアップ」 |
| Codex CLI で使いたい | 置き場所を `~/.codex/skills/tako-lp-one-shot/` にする。画像は Codex 自身が作るので追加ツール不要。それ以外の手順は同じ |
| Node が無い / 古い | https://nodejs.org/ の LTS。入れ直したら Claude Code を再起動 |
| フォルダ名が日本語・スペース入り | 動くが事故が増える。サイトのフォルダ名は英数字とハイフンにする（例: `mame-kakeibo`） |

## 作っている途中

| 困りごと | 直し方 |
| --- | --- |
| 質問が多くて途中で分からなくなった | 分からない項目は空欄でよい。スキルが決めて、納品時に「補完した箇所」として列挙する。後から直せる |
| 10案のどれもピンとこない | 「2と5を混ぜて」「3の色だけ白に」「全部黒背景で出し直して」と言う。出し直しは何度でも可 |
| 生成されたアイコン（エンブレム）が要らない | 10案の「アイコン」列を見て、本人写真 / ロゴ / なし の案を選ぶ。既に作った後なら「アイコンを写真に差し替えて」 |
| 画像生成が「FAIL」になる | Codex のログイン切れが多い。`codex login` してから「画像だけ作り直して」。安全フィルタの時はスキルが言い換えて再試行する |
| Codex が無い / ChatGPT の有料プランが無い | 画像なしで完成させて `prompts.md` を出す経路に自動で切り替わる。ChatGPT 無料枠・Canva・Midjourney などで作って `images/` に入れ「画像を入れた」 |
| 自分の顔写真を使いたい | 使える。生成しないだけ。`icon:` か `images: ./photos/` に置く。10案で「本人写真」の案を選ぶ |
| 数字チェックで FAIL する（「3ステップ」「24時間」など） | 実績ではない数字表現は brief の `numbers_ok:` に列挙する。スキルが自動で追記して再実行する |
| 途中で止まった / 会話が長くて続けられない | 新しい会話で「スタート」→ `9 続きから`。`<site>-src/recipe.json` と `copy.md` から再開する |
| プレビューのスクショが真っ黒 | Claude Code のブラウザ画面の癖。サイトは壊れていない。自分のブラウザで `index.html` をダブルクリックして見る |
| ブラウザで開くと演出が動かない | 裏タブだとアニメが止まる。タブを前に出すと動く。`prefers-reduced-motion` を OS で有効にしていると意図的に止まる |
| スマホで確認したい（公開前） | 一番簡単なのは「公開して」で Cloudflare Pages に一度上げて URL をスマホで開く。ローカルなら同じ Wi-Fi で `http://<PCのIPアドレス>:5173` |

## 直したい時の言い方

| やりたいこと | こう言う |
| --- | --- |
| 文言を変える | Claude に言わなくてよい。`<site>-src/台本.md` を開いて本文を書き換えて保存する。`python scripts/watch-copy.py <site>` を動かしておけば保存のたびに反映、動かしていなければ「台本を反映して」 |
| 文言を Claude に頼む | 「ヒーローの見出しを『○○』に」「2つ目のカードの本文を短く」 |
| 色・雰囲気を変える | 「全体をもう少し明るく」「金を減らして白を増やして」「World を paper-white にして作り直して」 |
| 画像を差し替える | `assets/img/` の同名ファイルを上書きして「画像を差し替えた」 |
| 演出を弱める / 強める | 「開幕のローダーを消して」「スクロールの動きをもっと派手に」「カーソルの演出を外して」 |
| セクションを足す・消す | 「FAQ を足して」「年表を消して」 |
| フォームを付ける | 「このURLのフォームを付けて https://…」 |
| 同じ構成で別の題材 | `recipe.json` を渡して「このレシピで○○のページを作って」 |

## 公開した後

| 困りごと | 直し方 |
| --- | --- |
| 画像が出ない | `index.html` だけ上げている。フォルダごと（`assets` を含めて）上げる |
| フォームが届かない | Cloudflare Pages はフォームを受け取れない。`gform`（Google フォーム）/ `embed` / `line` のどれかにする。元サービスの設定を確認し、テスト送信を1回する |
| LINE の QR 画像が欲しい | LINE Official Account Manager → 友だちを増やす → 友だち追加ガイド → QR コードをダウンロード。`line_qr:` に置く |
| OGP（SNS のカード）が古いまま | SNS 側のキャッシュ。X は Card Validator、Facebook は Sharing Debugger で再取得。反映まで数時間かかることがある |
| 独自ドメインで本名が出た | ドメイン側の WHOIS 代行公開をオンにする（Cloudflare ではなくドメイン会社の設定。Cloudflare Registrar で取った場合は自動で代行公開） |
| 更新したのに変わらない | ブラウザのキャッシュ。シークレットウィンドウで確認。Cloudflare Pages の Deployments で最新が Production か見る |
| WordPress や既存サイトに埋め込みたい | このスキルは単独ページ用。別サブドメイン（`lp.example.com`）で公開してリンクするのが確実。iframe 埋め込みは演出が崩れる |
| 複数ページ・ブログにしたい | 対象外。1ページ完結。複数作るなら別フォルダで別 LP |

## お金と時間の目安

- 1本あたり: Claude Code のトークン 20〜40万（画像込み）。Codex は画像1枚 1〜3万トークン（ChatGPT の枠内）
- 所要: おまかせ 10〜15分、詳細 20〜30分（画像生成が7割）
- Cloudflare Pages: 無料。帯域・アクセス数の上限なし
