質問に答えて、番号を選ぶ。
それだけで公開できるLPが出てくる。

このページは Tako_LP_One-Shot の使い方です。ブラウザで開いたまま、横で Claude Code（または Codex）を動かしてください。所要は導入10分、1本目のLPは目安20分です。

00これは何？

Claude Code / Codex に入れて使う「LP制作スキル」です。スタート と打つとメニューが出て、質問に答え、10案から番号を選ぶと、公開用のフォルダ（index.html と画像一式）が完成します。

できること
セールスレター / メール・LINE登録ページ / 簡易ホームページ / 自己紹介 / ポートフォリオの入口 / リンクまとめ の6用途。文章、画像、動き、スマホ対応、公開前チェックまで。
できないこと
決済、会員機能、ブログ、複数ページのサイト。1ページ完結のLP専用です。複数作る時は別フォルダで別LPにします。

01導入（最初の1回だけ。ターミナルは使いません）

Claude Code か Codex のデスクトップアプリだけで完結します。黒い画面（ターミナル）は開きません。

  1. デスクトップアプリを入れる。Claude Code（Pro 以上のプラン）または Codex。すでに使っていればスキップ。
  2. スキルのフォルダを置く。ダウンロードした zip を展開し、Tako_LP_One-Shot フォルダを次の場所に入れる。
    Claude Code: C:\Users\<あなた>\.claude\skills\（Mac: /Users/<あなた>/.claude/skills/）
    Codex: C:\Users\<あなた>\.codex\skills\（Mac: ~/.codex/skills/）
    隠しフォルダです。エクスプローラーのアドレス欄に %USERPROFILE%\.claude\skills と打つと開きます（Mac は Finder で Cmd+Shift+G → ~/.claude/skills）。
    自分で置くのが不安な人は、アプリのチャットにこう貼るだけでも入ります: ダウンロードフォルダの Tako_LP_One-Shot.zip をスキルとして導入して
  3. アプリを開き直して、チャットに セットアップ と打つ。スキルが必要なものを全部入れます（数分）。「許可しますか」のダイアログが出たら「はい」「許可」を押してください。
  4. Codex のログイン（画像の自動生成に使います）。ブラウザが開くので Authorize を1回押す。これだけ。
  5. チャットに スタート と打つ。メニューが出れば準備完了です。

「セットアップ」で入るもの

入るもの何に使う
Node.jsプレビュー、公開前チェック、HyperFrames
Python + Pillow画像の変換
Codex CLI画像の自動生成（ChatGPT の有料プランの枠で動く）。Codex アプリが入っていれば同梱のものを使う

02「スタート」とメニュー

スタート と打つと、環境チェック（数秒）のあとにメニューが出ます。初めてなら 1。

Tako_LP_One-Shot ── 何をしますか？
1  新しくLPを作る
2  brief.md から作る（すでに書いてある人）
3  完成例を見る（3サイトの公開URL + 世界観見本帳）
4  作ったLPを直す
5  画像だけ作る
6  使い方を読む
7  公開する（Cloudflare Pages）
8  環境を整える
9  続きから
止まるのは3回だけ。①質問への回答 ②10案の選択 ③（ChatGPT で手動で画像を作る人だけ）画像を入れた合図。それ以外は最後まで自動で進みます。

03作り方を選ぶ

作り方を選んでください
1 おまかせ（6問、5分）
2 詳細ヒアリング（20問、15分。仕上がりにこだわる人）
3 素材を貼る（SNS・自己紹介記事・既存LPの URL や文章。質問はほぼ不要）
  • 迷ったら 1。質問は1つのメッセージにまとまって来ます。分からない項目は空欄で構いません。スキルが補い、納品時に「補った箇所」を列挙します。
  • Threads / X / Instagram のプロフィールや note の自己紹介記事があるなら 3。URL を貼るだけで口調・実績・リンクを読み取ります。1 や 2 と併用すると一番速くて質が高いです。
  • 数字（実績）は、あなたが書いたものだけが使われます。書いていない数字をスキルが作ることはありません。

0510案から選ぶ

組み立てる前に、必ず10案が表で出ます。各案に「アイデア（比喩）」「文字の主役」「レイアウトの型」「世界観の No.」が書いてあります。

  1. 末尾の No. のリストをコピーして、見本帳の検索欄に貼る。10案の世界観だけが並ぶので、画像で見比べる。
  2. 番号で返事する。「3番で」「2と5を混ぜて」「3で色だけ白に」「全部黒背景で出し直して」も可。「おまかせ」なら1番で進む。
  3. 「アイコン」列が「生成エンブレム」の案を選ばなければ、勝手にエンブレムは付きません。

06画像の4つの経路

あなたの状況どうなる
Codex CLI がある画像を自動生成（1枚1分）。その間に本体が組まれる
ChatGPT はあるが Codex は無い画像なしで完成 → prompts.md が出る → ChatGPT でプロンプトを貼って画像を作り、images/ に保存 → 「画像を入れた」と言う → 差し替わる
手持ちの写真・画像がある最初の質問で場所を伝えれば取り込む。本人写真もここ
画像は要らない文字・色・図形だけで完成。あとから入れることもできる

KV（一番上の1枚）だけでも入れると見た目が大きく変わります。Canva や Midjourney で作った画像も使えます。

07確認して直す

納品メッセージに、案の名前 / 動く演出 / 公開手順 / スキルが勝手に決めた箇所 / 残タスク が書かれます。勝手に決めた箇所だけ目を通してください。

文言は 台本.md で自分で直せる

サイトのフォルダの隣に <サイト名>-src/台本.md ができます。見出しや本文が「## キー」ごとに並んでいるので、本文を書き換えて保存するだけです。

# 反映（保存のたびに自動で反映したい時）
python scripts/watch-copy.py <サイトのフォルダ>

# 1回だけ反映
python scripts/apply-copy.py <サイトのフォルダ>

08公開する（Cloudflare Pages、無料）

一番簡単なのは、チャットに 公開して と打つことです（メニュー 7 も同じ）。

  1. スキルが Cloudflare のログイン画面をブラウザで開く。Allow を1回押す（初回だけ。アカウントが無ければ https://dash.cloudflare.com/sign-up で作る。無料・カード不要）。
  2. スキルがフォルダをアップして、https://<名前>.pages.dev の URL を出す。
  3. その URL をスマホでも開いて確認する。初回は反映まで1〜2分かかることがある。
今 Netlify にあるLPを移したい人は MIGRATE.html。チャットに「Netlify の https://… を Cloudflare Pages に移行して」と言えば、取り出しから公開までスキルがやります。
無料でも止まりません。Cloudflare Pages はアクセス数・帯域の上限が無いので、バズっても 503 になりません。更新は「公開して」と言えば同じ URL に上書きされます。自分でドラッグ&ドロップしたい人、独自ドメイン、フォームの受け皿は PUBLISH.html（メニュー 7）に書いてあります。

09LINE・登録フォーム

質問3の「受け皿」に URL や埋め込みコードをそのまま貼るだけで、スキルが種類を判定して設置します。

貼るもの設置のされ方
LINE の友だち追加 URL（lin.ee / line.me）LINE 色のボタン。QR 画像があれば横に
UTAGE / MyASP などの登録ページ URLページ内にフォームを埋め込む、または登録ページへ飛ばす
配信ツールの埋め込みコードそのまま埋め込む
Google フォームの埋め込み（配信ツールが無い人）iframe を貼るだけで動く。回答はスプレッドシートへ
note / 販売ページの URL購入ボタンにする

「テスト送信して届くか確認してください」と言われたら1回だけ送ってみてください。詳細は parts/forms.md。

10困った時

困りごと直し方
.claude / .codex フォルダが見つからない隠しフォルダ。Windows はエクスプローラーの「表示 → 隠しファイル」、Mac は Finder で Cmd+Shift+.。アドレス欄に %USERPROFILE%\.claude と打っても開ける
「スタート」と打っても別のスキルが反応する/Tako_LP_One-Shot と打つか、「たこLP」と打つ
python と打つと Microsoft Store が開くhttps://www.python.org/ から入れ、インストール時に「Add to PATH」にチェック
画像生成が FAIL になるCodex のログイン切れが多い。codex login してから「画像だけ作り直して」。「モデルが新しいバージョンを要求」と出たら npm i -g @openai/codex@latest
10案のどれもピンとこない「2と5を混ぜて」「全部黒背景で出し直して」。出し直しは何度でも可
途中で止まった / 会話が長くなった新しい会話で「スタート」→ 9 続きから
プレビューのスクショが真っ黒Claude Code のブラウザ画面の癖。自分のブラウザで index.html をダブルクリックして見る
公開したのに画像が出ないindex.html だけ上げている。フォルダごと上げ直す
更新したのに変わらないブラウザのキャッシュ。シークレットウィンドウで確認

もっと詳しい一覧は TROUBLESHOOTING.md（メニュー 6 のあとに「困った時」と言うと表示）。

11フォルダの中身（消さないで）

フォルダ / ファイル役割触る？
SKILL.mdスキルの手順書そのもの。Claude / Codex が読む触らない
recipes/辞書。骨格7種・世界観100種・演出10種・ヒアリングの質問・10案の作り方・センスの基準。これが無いとLPが作れません触らない
worlds/あなたが「独自に作って」で作った世界観（custom）の保存先。最初は空自動で増える
parts/フォームの設置方法、演出の実装、共通のモーション触らない
scripts/画像生成・変換・検査・台本の反映などの道具。Claude が実行する自分で使うのは台本の2つだけ
brief.template.md発注書のひな形。メニュー 2 で使うコピーして使う
history.json直近に作ったLPの組み合わせ。次に同じ顔にならないための記録触らない
MANUAL.html / SETUP.md / TROUBLESHOOTING.mdこのマニュアルと各手順書読む
PUBLISH.html / MIGRATE.html公開マニュアル（Cloudflare Pages）/ 移行マニュアル（Netlify から移す）。ブラウザで開く読む

作ったLPは、このフォルダの外（あなたが指定した場所）に <サイト名>/ と <サイト名>-src/ の2つで出ます。公開するのは前者、台本や brief は後者です。

Tako_LP_One-Shot 使い方マニュアル。このファイル（MANUAL.html）はダブルクリックでいつでも開けます。印刷にも対応。
