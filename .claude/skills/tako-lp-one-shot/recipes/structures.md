# 骨格（Structure）— 7種

骨格は「セクションの順番」「ヒーローの型」「画像の枚数と比率」「スクロールの進み方」を決める。世界観（色・書体・画風）は決めない。

## 用途別の既定

| use | 第1候補 | 第2候補 | 第3候補 |
| --- | --- | --- | --- |
| letter | letter | acts | journey |
| optin | deck | journey | letter |
| home | editorial | catalog | deck |
| profile | editorial | journey | acts |
| portfolio | catalog | deck | editorial |
| links | poster（1画面、文字が主役） | editorial（目次型） | deck |

`subject: work`（架空作品・ゲーム・映画・小説）は用途に関係なく `acts` を第1候補にする。

---

## acts — 幕構成

映画の公式サイトの型。「第一幕・第二幕」で進む。壮大さ・世界観の提示に向く。

- **ヒーロー型**: フルブリードKV + 画面幅いっぱいの巨大タイトル（英字 or 縦書き）+ 一行のタグライン + 2ボタン。
- **順番**: ローダー → ヒーロー → 第1幕 物語（3章カード + ムード画像）→ 第2幕 人物 or 特徴（切替ステージ）→ 第3幕 仕組み/敵/中身 → 第4幕 映像 or ギャラリー → 第5幕 世界（文字点灯の大文言）→ 情報（スペック表 + ニュース）→ 登録/CTA → フッター
- **画像**: 8〜10枚。KV 3:2、人物/特徴 4:5、ムード 3:2 ×3、ギャラリー 16:9 ×2。
- **モーション計画**: ローダー（進捗 or カウント）→ タイトル登場（スライス/マスク）→ セクションごとに1演出（章カードのステップ表示、人物切替のクロスフェード、点灯テキスト）。ヒーローでシグネチャーを1回自動発火。
- **使いどころ**: work / event。person でも「一代記」的に語るなら可。

## journey — 浮上・上昇

「深海から浮上」「0mから山頂へ」のように、1本の指標がスクロールに伴走する型。人の物語に向く。

- **ヒーロー型**: スプリット。左に一撃コピー + 実績、右にアイコンを囲む装置（リング・放射線・額縁）。
- **順番**: ローダー（指標が動く）→ ヒーロー → 実績ストリップ → 物語3章（各章に画像 + 指標が進む）→ 武器/強み（横スクロール or グリッド 6〜8）→ やらないこと/信念（3カード）→ 大引用 → CTA → フォロー → フッター
- **画像**: 6〜8枚。KV 3:2、章 3:2 ×3、背景 3:2 ×2、マスコット/象徴 3:2。
- **モーション計画**: 画面端に固定の指標（深度計・高度計・進捗）がスクロールで動く。章の画像は視差、本文は文字点灯。横スクロールは PC のみ、SP はグリッドに落とす。
- **使いどころ**: profile / optin（講師の物語を主役にする時）。

## deck — 一枚看板（スクロールスナップ）

※ links を deck で作る時も、1画面目は poster の型（巨大文字 + 番号付き目次）にする。角丸カードの行を縦に積まない。

1画面1メッセージのスライド。読み飛ばしを許さない。短いオプトインやリンクまとめに最適。

- **ヒーロー型**: 1枚目のスライドがそのままヒーロー。コピー + ブロブ形の画像 + バッジ + 流れるリボン。
- **順番**（optin の場合）: 表紙 → あるある（問題）→ 参加型スライド（シグネチャー）→ 中身（7日/5ステップ）→ 送る人 → 受け取れるもの → フォーム → フッター。5〜8枚。
- **画像**: 5〜7枚。すべて 1:1 にトリミングできる構図（中央に被写体）。
- **モーション計画**: 各スライドに入るたびにタイムライン再生（画像が弾んで出る → 見出し文字が跳ねる → 本文）。右端にドット（ラベル付き）。上部にページ番号とゲージ。キーボード↑↓対応。`scroll-snap-type: y mandatory`、SP は `proximity` に落としてもよい。
- **使いどころ**: optin / links / portfolio（1作品1画面）。

## letter — 縦長レター

読ませる型。中央760px、画像は最小限、文字の強弱で引っ張る。

- **ヒーロー型**: タイポのみ。バッジ + 差出人 + H1 + 1行の約束。画像なし or 小さなアイコン。
- **順番**: 固定バナー → ヒーロー → 吹き出し（挨拶）→ 核心メッセージ枠 → 実績 → 問題 → 共感チェック → 断言 → 物語 → 解決策 → 中身（章カード）→ 特典 → 価格 → 保証 → FAQ → 追伸 → 期限警告 → 最終CTA → フッター
- **画像**: 0〜5枚。使うなら本文中に 3:2 で小さく。
- **モーション計画**: 読了プログレスバー、吹き出しのポップ、価格の打ち消し線 → 新価格のカウント、期限のカウントダウン（実在の期限がある時だけ）。派手な演出は入れない。文字のリズムが主役。
- **使いどころ**: letter / optin（長文で説得する時）。

## catalog — 図鑑

最初から一覧が見える型。作品・メニュー・キャラクターの見せ場。

- **ヒーロー型**: グリッドがそのままヒーロー。上に短い見出し1行、その下に画像グリッド（3〜4列、SP 2列）。
- **順番**: 見出し → グリッド（10〜16）→ 各項目の詳細（モーダル or 展開）→ 選び方/依頼方法 → CTA → フッター
- **画像**: 10〜16枚、正方形 or 4:5 統一。
- **モーション計画**: グリッドの登場は波状スタガー。ホバーで画像が持ち上がりキャプションが出る。クリックでモーダル（背景ぼかし）。フィルタタグで並び替え（GSAP Flip 不要、CSS order で可）。
- **使いどころ**: portfolio / home（メニュー）/ work（キャラ図鑑）。

## poster — 一枚のポスター（links の第1候補）

リンクまとめを Linktree に見せないための型。**名前の巨大文字と番号付きの目次**で1画面を組む。`recipes/taste.md` の「リンクまとめの正しい型」を守る。

- **ヒーロー型**: 画面幅いっぱいの名前（英字なら 14〜20vw、日本語なら縦書きも可）。その上か脇に一言。背景は本人の実写1枚か、World の色面。象徴物の生成画像は使わない。
- **順番**: 名前 → 一言 → 目次（01 / 02 / 03 …、罫線、大きな表示名、小さな一言）→ 主リンクだけ色面のボタン → 実績を出すなら数字を1つだけ巨大に → フッター
- **画像**: 0〜1枚（本人写真 or 抽象の色面）。生成するなら抽象のみ。
- **モーション計画**: 名前の文字が1文字ずつ横から入る（または縦書きが上から降りる）/ 目次の罫線が左から引かれる / ホバーで表示名が太る・色面が伸びる / 主リンクの色面が呼吸する。シグネチャーは1つ（letters-fall か tear か none）。
- **使いどころ**: links / profile（短い自己紹介）。

## countdown — カウントダウン

日付が主役。発売・イベント・締切。

- **ヒーロー型**: 画面の半分が時計（日:時:分:秒）。残りに一行コピーとCTA。背景に1枚。
- **順番**: 時計ヒーロー → 何が起きるか（3点）→ 会場/形式 → 登壇者/出演 → 参加方法 → CTA（時計再掲）→ フッター
- **画像**: 3〜4枚。KV 3:2、他 1:1。
- **モーション計画**: 数字のフリップ、秒の脈動、期限を過ぎたら「開催中/終了」に自動切替。**期限は brief の `deadline` にある時だけ**。無ければこの骨格は選ばない。
- **使いどころ**: event。

## editorial — 雑誌

余白と書体で品を出す型。白でも黒でも成立する。

- **ヒーロー型**: マストヘッド（左ナビ・中央名前・右号数）+ 名前の巨大セリフ + 右に1枚（額縁）。
- **順番**: マストヘッド → ヒーロー → About（2段組・ドロップキャップ）→ 年表 or 実績 → 作品/事例（非対称グリッド3〜4）→ Index（発信先リンク）→ Contact → フッター
- **画像**: 5〜8枚。ヒーロー 4:5、作品 3:2 / 4:5 / 21:9 を混ぜる、About と Contact に 3:2 を1枚ずつ。
- **モーション計画**: 名前はマスクから浮上。画像は上から開く（clip-path）+ 視差。年表の罫線がスクロールで伸びる。右下に「p.02 / 06」のページ番号。上に読了線。リンクはホバーで左余白が開く。
- **使いどころ**: profile / home / portfolio。

---

## 共通の約束

- どの骨格も **最初の1画面で「何のページか」と「行動1つ」が分かる**。
- CTA は骨格が指定する位置に置き、文言は全箇所で同じ。
- SP（375px）で必ず崩れないこと。横スクロール系は SP でグリッドに落とす。
- 骨格名をセクション見出しに出す時は World の語彙で言い換える（acts なら「第一幕 / Act I / 壱」、journey なら「-8,000m / STEP / 第一合目」など）。
