# デザイン10案 — 作る前に必ず見せて、選んでもらう

ヒアリング（と素材抽出）が終わったら、**組み立てる前に10案を提示して番号で選んでもらう。** これが2回目（詳細モードでは3回目）の停止。「おまかせ」と返ってきたら 1 番で進む。「2と5を混ぜて」「3の色だけ金に」のような指定はそのまま採用する。

## 出し方

1メッセージに、抽出結果の要約（素材があれば）→ 10案の表 → 各案の1〜2行説明 → 「番号で選んでください」の順。

```
## デザイン案（番号で選んでください。「1と4を混ぜて」「3で色だけ変えて」も可）

| # | 案の名前 | 一言 | 世界観 | 骨格 | 演出 | 画像 | アイコン |
|---|---|---|---|---|---|---|---|
| 1 | 黄色い号外 | 黄色い紙に黒の巨大文字。名前が画面幅いっぱい | brutal | deck | letters-fall | なし | 本人写真 |
| 2 | 白い目次 | 雑誌の目次。番号と罫線と大きな見出し | paper-white | editorial | none | 手持ち1枚 | 本人写真 |
| ... |

1 **黄色い号外** — アイデア: 号外新聞。名前が黄色い紙に 16vw の黒文字で横一列、下線が引かれる。目次は罫線と番号。クリックで文字が落ちる
2 **白い目次** — アイデア: 雑誌の目次ページ。名前は 12vw の細いセリフ、右に本人写真1枚。リンクは「01 — LINE」の行が左から罫線ごと現れる

見本帳で見比べる用（そのままコピーして、見本帳の検索欄に貼ると10案の世界観だけが並びます）
```

No.041
No.005
No.088

No.034
No.052
No.096
```
```

- 表の「世界観」列は `No.023 sakura` の形。**末尾に「見本帳で見比べる用」として、10案の世界観の No. を案の順に1行1つで縦に並べたコードブロックを必ず付ける**（`No.` + 3桁。同じ世界観が2案あれば2回書く。見本帳の検索欄はこの形式の貼り付けに対応している）

## 10案の作り方（多様性の規則）

必ず守る:
- **写実の象徴物（紋章・メダル・王冠・金塊）を使う案は出さない。** 生成アイコンを使うなら「スタイル化したイラスト」か「抽象の色面」と明記する
- **明るい World（白・生成り・黄・パステル）の案を4つ以上**。黒は「暗さに意味がある案」だけ
- **世界観は最大2案まで同じ**（10案で5種類以上の World）。World は `recipes/worlds.md` の100種から。`direction:` で選ばれたグループを6案以上、隣のグループ2案、意外性2案（`recipes/hearing.md`「方向性 → 世界観の絞り込み」）
- **骨格は3種類以上**
- **「画像なし」の案を2つ以上**（`none` の手法。Codex が無い人・写真が無い人のため）
- **本人写真・手持ち画像を使う案を1つ以上**（写真があると分かっている時）
- **生成アイコン（エンブレム等）を使う案は「アイコン」列に明記**し、`avoid:` に「エンブレム」「生成アイコン」があれば出さない
- **10グループ（dark / light / cute / retro / nature / business / genre / minimal / cool / gira）のうち、選ばれたグループ + 隣 + 意外性 で3つ以上をカバー**。`direction:` が無ければ先に 1-f で聞く
- 表の「世界観」列には No. と id を書き（例: No.023 sakura）、末尾に「特典の世界観見本帳（Tako_LP_Lookbook/index.html）で No. を検索すると見比べられます」と一言添える
- **演出は最大2案まで同じ**
- `history.json` の直近3件と同じ 世界観×骨格 の案は出さない

各案に必ず書くこと（`recipes/taste.md` を先に読む）:
- 案の名前（4〜8字の日本語）
- **アイデア（比喩）1行**。「潮が引くと来る」「深海から浮上」のように、サイト全体の動きと画像がここから決まる
- **文字の主役**: 何の文字を、どのくらいの大きさ（vw）で、どう置くか（横一列に散らす / 縦書き / 画像に重ねる / 透かし）
- **レイアウトの型**: 重ね / 散らし / グリッド / ポスター / 雑誌 / 看板 のどれか（中央揃えの縦積みは不可）
- 一言（読者が最初の1画面で受ける印象）
- 世界観 / 骨格 / 演出 / 画像（生成N枚 / 手持ちN枚 / なし）/ アイコン（本人写真 / ロゴ / 生成エンブレム / なし）
- 1〜2行の説明: ヒーローで何が見え、何が動くか。CTA の見た目

## 選ばれた後

- 選択を `recipe.json` に保存し、案の名前を `recipe.title` に入れる。
- 「混ぜて」の場合は、骨格は1つ目の案、世界観・色は2つ目の案、と決めて1行で確認を見せる（返事は待たない）。
- ここから先は止まらない（画像の ChatGPT 手動経路を除く）。
