# ヒアリング — おまかせ（6問）と 詳細（20問）

入口は2つ。どちらでも最後は「10案から選ぶ」（proposals.md）に合流する。

| モード | 質問数 | 止まる回数 | 向く人 |
| --- | --- | --- | --- |
| おまかせ | 6問（1メッセージ） | 2回（回答 → 10案の選択） | とにかく早く1本ほしい。素材が少ない |
| 詳細 | 20問前後（2メッセージに分割） | 3回（前半 → 後半 → 10案の選択） | 実績・ストーリー・素材が揃っている。仕上がりにこだわる |

どちらも **素材貼り付け**（materials.md）を併用できる。SNS の URL や自己紹介記事を貼れば、質問の多くは抽出で埋まり、ユーザーには「抽出結果の確認」だけを求める。

---

## おまかせ（6問）— 1メッセージで聞く

1. 何のページ？（セールスレター / メール・LINE登録 / 簡易ホームページ / 自己紹介 / ポートフォリオ入口 / リンクまとめ）
2. 名前（人・商品・作品名）と、一言で何者か
3. 読者にしてほしい行動1つと、その受け皿。URL か埋め込みコードをそのまま貼る（無ければ「なし」）
4. 使ってよい実績・数字（本人の言葉どおり。無ければ「なし」）
5. 誰に読ませたいか
6. 見た目の方向性（番号で。2つまで）: ①ダーク・壮大 ②明るい・上品 ③かわいい・ポップ ④レトロ ⑤和・自然 ⑥ビジネス・テック ⑦ジャンル（ホラー・SF・ゲーム） ⑧ミニマル ⑨かっこいい・クール ⑩商材屋（ギラギラ） / おまかせ。参考URLがあれば

`links` の時は 1-b-2（SKILL.md）のリンク一覧を追加で聞く。

---

## 詳細（20問）— 2メッセージに分けて聞く

**前半（A・B）を1メッセージ、後半（C・D・E）を1メッセージ。** 用途別の追加質問は後半の末尾に付ける。「分からない項目は空欄でOK」と必ず添える。

### A. 基本
1. 何のページ？（6用途から）
2. 名前と肩書き（表記ゆれがあれば正式なもの）
3. 一言で何者か（読者に最初に伝わってほしい1文）
4. 読者にしてほしい行動1つと、その受け皿（URL / 埋め込みコード / なし）
5. 誰に読ませたいか（年齢・状況・今の悩み）
6. 読者が今「信じていること」や「誤解していること」（ページで覆したいこと）

### B. 中身
7. 提供するもの（講座・商品・サービスの中身を箇条書きで）
8. 実績・数字（本人の言葉どおり。出したくない数字があればそれも）
9. ストーリー3行（きっかけ → 転機 → 今）
10. よく使う言葉・口癖・決めゼリフ、絶対に使いたくない言葉

### C. 素材
11. 写真・アイコン・ロゴ（ファイルを置く場所 or URL）。顔出しは OK か
12. 既に決まっている色・フォント・ブランドの決まり（無ければ「なし」）
13. SNS / 自己紹介記事 / 既存LP の URL（貼れば口調・実績・リンクを抽出する）

### D. 見た目
14. 方向性（番号で。2つまで）: ①ダーク・壮大 ②明るい・上品 ③かわいい・ポップ ④レトロ ⑤和・自然 ⑥ビジネス・テック ⑦ジャンル（ホラー・SF・ゲーム） ⑧ミニマル ⑨かっこいい・クール ⑩商材屋（ギラギラ） / おまかせ
15. 好きなサイト・ブランド・雑誌を3つ
16. 嫌いな見た目・やってほしくないこと（例: エンブレム、縦書き、丸っこい、写真多め）
17. 画像はどうする？（AIで自動生成OK / 手持ちを使う / いったん画像なしで作って後から入れる）

### E. 公開
18. 公開先（Cloudflare Pages / 他 / 未定。迷ったら Cloudflare Pages）
19. 独自ドメインの有無
20. 期限やイベント日（あれば。カウントダウンに使う）

### 用途別の追加（後半の末尾）
- **letter**: 価格 / 保証 / 販売期限 / 特典の一覧 / よく聞かれる質問3つ
- **optin**: 特典の中身 / 配信の頻度と形式 / 登録後に何が起きるか
- **home**: メニューと価格 / 営業時間・対応エリア / 問い合わせ方法
- **profile**: 年表（年と出来事） / 今やっていること / 依頼できること
- **portfolio**: 作品リスト（タイトル・年・一言・画像の場所）
- **links**: 1-b-2 のリンク一覧

## 方向性 → 世界観の絞り込み

方向性の番号は `recipes/worlds.md` のグループ id に対応する: ①dark ②light ③cute ④retro ⑤nature ⑥business ⑦genre ⑧minimal ⑨cool ⑩gira。
素材貼り付け（1-d）だけで来た時や、回答が空欄・「おまかせ」の時は、**10案の前に方向性だけを1回聞く**（SKILL.md 1-f）。これは10案の選択とは別の、短い1往復。

絞り込みの規則:
- 選ばれたグループの World を **10案のうち6案以上** に使う（同じ World は最大2案）
- 隣のグループ（例: ⑩商材屋 → ①ダーク・⑨クール、③かわいい → ⑤和・自然・②上品）から **2案**
- 残り **2案は意外性枠**。ユーザーが選ばなかったグループから、読者と用途に合うものを出す。ここで「思っていたのと違うけど良い」が起きる
- 2グループ選ばれたら 4案 + 4案 + 隣1 + 意外性1
- 見本帳の World は見本。色だけ変える、2つを混ぜる、`custom` で6問に答えて作る、が常にできる。案の説明に「見本帳の ○○ をベースに色を△△に」と書いてよい

## 回答の扱い

- 答えは `brief.md` に書き起こす。空欄は **スキルが決めて、納品時に「補完した箇所」として列挙**する。
- 「なし」と「空欄」は区別する。「なし」は意図的（例: 実績を出さない）。空欄は補完対象。
- 16（嫌いな見た目）は `avoid:` に入れ、**10案の生成時に除外条件**として効かせる。ここに「エンブレム」とあれば生成アイコン案を出さない。
- 11 で顔出し NG なら、生成画像は象徴物のみ、本人写真は使わない。
- 素材（13）が貼られたら materials.md の手順で抽出し、抽出結果を 10案と同じメッセージで見せる。
