# 素材貼り付け — SNS・自己紹介記事・既存LPから作る

ユーザーが URL や文章を貼るだけで brief の大半を埋める。**抽出したものは必ず本人に見せて確認してもらう**（10案と同じメッセージで）。

## 受け付けるもの

| 貼られたもの | 取り方 |
| --- | --- |
| Threads / X / Instagram のプロフィール URL | ブラウザで開き、プロフィール文・固定投稿・直近の投稿（見えている範囲）を読む。ログインが要る部分は読まない |
| note / ブログの自己紹介記事 URL | 本文を全部読む |
| 既存の LP / ホームページ URL | 見出し・実績・CTA・リンク先・使っている色とフォントを読む |
| 文章の貼り付け（自己紹介文・プロフィール・過去の投稿） | そのまま素材にする |
| 画像（アイコン・ロゴ・写真）のパス | `images/` にコピーして `icon:` `images:` に書く |

## 抽出する項目

| brief の項目 | 抽出元 | 規則 |
| --- | --- | --- |
| `name` / 肩書き | プロフィール名・自己紹介の冒頭 | 表記はそのまま。愛称と本名が両方あれば両方書く |
| `facts` | プロフィール文・固定投稿・記事中の数字 | **本人が書いた数字だけ**。「約」「以上」も本人の表記どおり。他人の引用や推測は入れない。出典（どの投稿か）を隣に書く |
| `voice` | 直近の投稿10〜20本 | 一人称 / 語尾 / 口癖 / 絵文字の有無 / 敬語かタメ口か / 決めゼリフ を5行で。voices.md の6種のどれに近いかも書く |
| `audience` | 投稿の呼びかけ相手 | 「〜な人へ」「〜で悩んでる人」の表現をそのまま |
| `timeline` | 自己紹介記事の経歴部分 | 年と出来事。年が書いていないものは入れない |
| `links` | プロフィールのリンク・記事内リンク | URL ごと。lit.link や Linktree があれば中のリンクも |
| `offers` | 固定投稿・記事の CTA | 何を、どこで、いくらで（書いてあれば） |
| `avoid` | 本人が批判している見た目・手法 | 例:「怪しい系はやらない」→ hype 文体を避ける |
| 既存の色・フォント | 既存 LP | 主色2つ・書体名。無ければ空 |

## 見せ方（10案の前に置く）

```
## 貼っていただいた素材から読み取ったこと（違っていたら直してください）

- 名前 / 肩書き: …
- 一言: …（固定投稿より）
- 実績: 「note 1万部突破」「累計6,000万」（プロフィール文より）
- 口調: 一人称「俺」、語尾「〜だわ」「〜やん」、絵文字なし、精神論に否定的 → 文体 honest
- 読者: …
- リンク: LINE（lin.ee/…）、note（…）
- 出していない数字は使いません。
```

## やってはいけないこと

- 見えない投稿・削除済みの内容を推測して書かない
- 数字を丸めない、増やさない、単位を変えない
- 他人の投稿にある本人の評判（「〜さんはすごい」）を実績にしない
- 貼られた URL の外へ勝手に辿らない（プロフィールのリンク先は1段だけ可）
