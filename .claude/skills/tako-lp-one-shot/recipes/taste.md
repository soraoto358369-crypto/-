# センスの基準 — 何が「良い」で、何が「安い」か

出典: MUUUUU.ORG「ダイナミックな動き」151サイト、LEAPY「動きのあるWebサイト事例」、および実際に開いた14サイト（COC / トンマナ / Rollbahn 25th / iro Inc. / SHIBUYA STREET LIVE / EIGHT DESIGN / POP IS YOU SAKAE / コクヨ / ポジティブドリームパーソンズ / OASIZ / 廣野鐵工所 採用 / beatfic / シーベジスタンド / TBWA\HAKUHODO）。
このスキルの完成例で「良い」と評価されたのは hollow-tide と octohito-lp。「ひどい」と評価されたのは takosuke-links（金のタコのエンブレム）。その差もここに書く。

**10案を作る時と、組み立てる時に、必ずこのファイルを読む。**

## 良いサイトに共通していた10のこと

1. **文字が主役。** 見出しは画面幅いっぱい（10〜20vw）、文字間を広げて横一列に散らす、画像に重ねる、縦書きにする。「OASIZ」「ENJOY YOUR GROWTH」「THE CULTURE MONSTER.」「POP IS YOU」。画像は文字を支える側。
2. **サイトに1つの「アイデア（比喩）」がある。** 雪のように降るお菓子（COC）、混沌を制する渦（OASIZ）、カルチャーの怪物（渋谷）、成長（廣野）。hollow-tide は「潮が引くと来る」、octohito は「深海から浮上」。**アイデアが無いサイトは、どんなに装飾しても安い。**
3. **重ねる・散らす・ずらす。** 文字の後ろに写真、写真の前に文字、ブロブで切り抜いた写真、透かしの巨大文字、タイル状のグリッド、非対称。**中央揃えで縦に積むだけの構成は1つもなかった。**
4. **色は「1つの強い色 + 白か黒か生成り」。** 黄色×黒（廣野）、緑×黒（TBWA）、緑×白（OASIZ）、赤×白（シーベジ）、紺（Rollbahn）。金グラデ・多色グラデ・ネオン二色は稀。**「黒×金＝高級」は定番ではない。**
5. **白・生成り・黄色の明るいサイトが半分以上。** 黒背景は「暗さに意味がある時」（映画、深海、夜のライブ）だけ。
6. **動きはアイデアから決まる。** お菓子が浮く、渦が回る、タイルが波打つ、文字が流れる（マーキー）、ローダーに顔がある（EIGHT の「8」）、スライド番号「1/3」「2 — 5」。**演出の在庫から選ぶのではなく、比喩から1つ作る。**
7. **写真と映像は本物。** 商品・人・現場の実写か、はっきりスタイル化されたイラスト（フラット、手描き、ポップな3D）。**写実の「象徴物」（金の紋章、王冠、金塊、宝石、豪華な小物）は1つも無かった。** これが最も安く見える。
8. **質感は素材として使う。** 黄色の紙のグレイン（廣野）、印刷のズレ、紙の繊維。装飾ではなく「紙・印刷物・看板」に見せるため。
9. **大きさの差が極端。** 11pxの字間広めのキャプションと、200pxの見出しが同じ画面にある。中間サイズを減らす。
10. **日本語の道具を使う。** 縦書き、漢字のグリッド（シーベジ「海藻 東京 大入 開運」）、手書きロゴ、明朝×ゴシックの混植、英字キャプションの併記。

## 安く見える7つのこと（禁止）

1. **写実の金属エンブレム・メダル・紋章・王冠・金塊・宝石。** 生成画像でこれを作らない。「たこ」「鷹」など名前の由来を紋章にしない。
2. **1つの素材を全部に塗る。** 金グラデを文字・ボタン・枠・粒・リングの全部に使う。金は「数字1か所」か「細い線」か「1つの光」に限定する。
3. **中央揃えの縦積み + 角丸カード + 左アイコン付きの行。** アプリの設定画面か Linktree に見える。リンク一覧でも、見出しの巨大文字と番号・罫線・大小の文字で組む。
4. **「cinematic photorealistic」の生成画像を白地や明るい World で使う。** 画風が World と合わない。明るい World はイラスト・切り抜き・抽象（インク、光、紙）にする。
5. **意味のない粒子・グレイン・グリッチ・カーソル。** 比喩に繋がらない演出はノイズ。
6. **英語のかっこいい言葉を意味なく置く。** 「PREMIUM」「LUXURY」「8 FIGURES」のような箔付けは禁止。英字は「名前」「番号」「章題」「キャプション」だけ。
7. **すべてを同じ大きさ・同じ重さで並べる。** 主役を1つ決め、残りは小さく薄く。

## 案（proposals）に必ず入れるもの

各案に「**アイデア（比喩）1行**」「**文字の主役**（何を何vwで、どう置くか）」「**レイアウトの型**（重ね / 散らし / グリッド / ポスター / 雑誌 / 看板）」を書く。この3つが書けない案は出さない。

## 画像の方針（World 別）

| World | 生成するなら | 生成しないなら |
| --- | --- | --- |
| 明るい系（light / cute / retro / nature の明るい World。paper-white / pastel-pop / brutal / retro-future / watercolor / mono など） | 切り抜きイラスト、フラット、手描き、ポップな3D、紙の質感、抽象の色面 | 本人写真、商品写真、CSS の色面と図形 |
| 暗い系（dark グループと、indigo-aizome / forest-moss / fintech-emerald など背景が暗い World） | 抽象（インク、光、霧、水、粒）、風景、後ろ姿、小物のマクロ。**象徴物は禁止** | 本人写真をモノクロ・高コントラストで |

生成画像の「被写体」は copy の比喩から取る。「深海」なら水と光、「潮」なら霧と海、「成長」なら伸びる線。名前の由来からは取らない。

## 良かった2作から抜き出した型（再利用してよい）

- **hollow-tide**: 巨大な英字タイトル（塗り + 中抜きの2段）/ 幕構成の章番号 / 1つの比喩（潮）から演出（雷・雨・信号弾）/ 実写風の霧の風景 / HUD のような小さなキャプション。
- **octohito-lp**: 深度計が伴走する比喩（浮上）/ 透かしの巨大文字「OCTOHITO」を背景に流す / 数字は金、他は白 / 横スクロールの8本 / 嫌いなものを打ち消し線で消す。
- **共通**: 最初の1画面に「タイトル・比喩・1行・行動」が全部ある。文字が大きい。画像は1枚で世界観を決める。

## リンクまとめ（links）の正しい型

Linktree に見せない。**「一枚のポスター」か「雑誌の目次」**として組む。
- 名前を画面幅いっぱいの文字で（縦書きでも可）。
- リンクは「01 / 02 / 03」の番号 + 罫線 + 大きな表示名 + 小さな一言。アイコンの角丸四角を並べない。
- 一番押したいものは色面（World の強い色）で1つだけ。
- 写真は本人の実写1枚（顔出し可の時）か、抽象の色面。象徴物の生成は禁止。
- 実績の数字を出すなら1つだけ巨大に。3つ並べた統計カードにしない。
