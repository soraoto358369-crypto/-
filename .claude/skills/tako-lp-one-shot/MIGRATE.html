移行マニュアル — 今 Netlify にあるLPを Cloudflare Pages に移す

所要 5〜10 分。Claude Code / Codex に任せられます。URL は https://<名前>.pages.dev に変わるので、配布済みのリンクは貼り替えてください。

01なぜ移すのか（購入者向けの短い説明）

  • Netlify の無料枠は 月100GBの帯域を超えると、そのアカウントの全サイトが止まります（503 "usage_exceeded"）。LPがバズった瞬間に落ちる、という一番困るタイミングで止まります。
  • Cloudflare Pages は 無料でも帯域・アクセス数の上限がありません。カード不要、操作も同じ「フォルダをアップするだけ」です。
  • だからこのスキルは、公開先を Cloudflare Pages に統一しています。

02A. 手元にサイトのフォルダがある場合（一番簡単）

チャットに 「このフォルダを Cloudflare Pages に公開して」 と言うだけ。スキルが scripts/publish.ps1（Mac: publish.sh）を実行し、初回はブラウザで Cloudflare のログイン画面が開くので Allow を押します。終わると新しい URL が出ます。

自分でやる場合: https://dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets → フォルダをドラッグ&ドロップ（PUBLISH.md 2章）。

03B. 手元にフォルダが無い場合（Netlify にしか残っていない）

Netlify が止まっていても、API からファイルを取り出せます。チャットにこう言ってください。

Netlify の https://xxxx-yyyy-123456.netlify.app を手元に取り出して、Cloudflare Pages に移行して

スキルがやること: 1. npx -y netlify-cli login（初回だけ。ブラウザで Authorize を押す） 2. python scripts/migrate-netlify.py <URL> <保存先> で全ファイルを取り出す 3. 取り出したフォルダの中に、Netlify でしか動かないもの（data-netlify のフォーム、.netlify.app へのリンク）が無いか点検して、あれば直す 4. scripts/publish.ps1 で Cloudflare Pages に上げて URL を出す

自分でやる場合: Netlify の管理画面 → サイト → Deploys → 一番上のデプロイを開く → 右上の Download で zip を落とし、展開したフォルダを Cloudflare にアップロード。

04C. 移行後にやること

項目 やること
リンクの貼り替え note / SNS / プロフィールに書いた旧 URL（.netlify.app）を新 URL（.pages.dev）に。X のプロフィールリンク、LINE のリッチメニューも忘れずに
LPの中のリンク 別のLPやサンプルへ .netlify.app でリンクしていたら、台本.md か index.html を直して再公開
フォーム Netlify Forms（data-netlify）は動かない。Google フォーム（gform）/ 配信ツールの埋め込み（embed）/ LINE（line）に切り替える（parts/forms.md）
独自ドメイン Netlify 側でドメインを外し、Cloudflare Pages の Custom domains に付け直す。DNS の CNAME を <名前>.pages.dev に
旧サイト 新 URL で問題なく動くのを確認してから、Netlify 側を削除（Site configuration → Delete site）。残しておくと帯域超過の原因になる

05よくある質問

  • URL を変えずに移せますか？ .netlify.app の URL は Netlify のものなので引き継げません。独自ドメインを使っていた場合はそのドメインごと移せるので URL は変わりません。
  • Cloudflare にもアップロード制限はありますか？ 1ファイル 25MB、1サイト 2万ファイル、デプロイ月500回。LPで到達することはありません。
  • Netlify にログインできない（パスワードを忘れた） Netlify の管理画面からダウンロードできないので、手元にフォルダが無ければ再生成が必要です。スキルの 9 続きから で recipe.json と 台本.md があれば同じLPを作り直せます。
