公開マニュアル — Cloudflare Pages で無料公開する（登録から更新まで）

所要 10 分。クレジットカード不要。無料でも帯域・アクセス数の上限が無いので、バズっても止まりません（Netlify の無料枠は帯域を超えると全サイトが止まるため、このスキルは Cloudflare Pages を標準にしています）。

一番簡単なのは メニュー 7「公開する」 です。スキルが Cloudflare にログインする画面を開き（ブラウザで Allow を1回押すだけ）、フォルダをアップして URL を出します。以下は自分でやる時の手順です。

011. アカウントを作る

  1. https://dash.cloudflare.com/sign-up を開く
  2. メールアドレスとパスワードで登録（無料プラン。カード不要）
  3. 届いた確認メールのリンクを押す
  4. ドメインの追加を聞かれても スキップ してよい（Pages に必要ない）

022. アップロードして公開する（ドラッグ&ドロップ）

  1. https://dash.cloudflare.com → 左メニュー Workers & Pages → Create → Pages タブ → Upload assets
  2. Project name に英数字とハイフンで名前を入れる（例: mame-kakeibo）。これが URL になる → Create project
  3. スキルが作った サイトのフォルダ（例: mame-kakeibo/。中に index.html と assets/ がある）を、点線の枠にドラッグ&ドロップ - フォルダごと落とす。index.html だけ落とすと画像が出ない - zip でもよい（zip の直下に index.html が来るように）
  4. Deploy site → 数十秒で https://<名前>.pages.dev が発行される
  5. その URL を開いて動作確認する。スマホでも開く。初回は反映まで1〜2分かかることがある（522 が出たら少し待つ）

033. サイト名（URL）を変える

URL はプロジェクト名で決まります。変えたい時は Pages の画面 → Settings → General → Project name を変更（URL も変わるので、配布済みのリンクがあれば貼り直す）。

044. 独自ドメインを付ける（任意）

  1. ドメインを取得する（Cloudflare Registrar が一番簡単。お名前.com などでも可）。WHOIS 代行公開を必ずオンにする（本名・住所が公開されるのを防ぐ）
  2. Pages の画面 → Custom domains → Set up a custom domain → ドメインを入力
  3. Cloudflare で取ったドメインなら自動で繋がる。他社なら表示される CNAME（<名前>.pages.dev）をドメイン会社の DNS 設定に入れる
  4. 反映まで数分〜数時間。HTTPS 証明書は自動で発行される

055. 更新する（内容を直した後）

方法 A（簡単）: Pages の画面 → Deployments → Create deployment → 新しいフォルダをドラッグ&ドロップ → Deploy。数十秒で差し替わる。URL は変わらない。過去の版にも戻せる（Rollback）。

方法 B（スキルに頼む）: メニュー 7 か「公開して」と言う。スキルが scripts/publish.ps1（Mac: publish.sh）を実行する。中身はこれ:

npx -y wrangler login                                   # 初回だけ。ブラウザで Allow
npx -y wrangler pages project create <名前> --production-branch main   # 初回だけ
npx -y wrangler pages deploy <フォルダ> --project-name <名前> --branch main --commit-dirty=true

066. 登録フォーム（メール・LINE）

Cloudflare Pages にはフォーム受信の機能が無いので、受け皿は外部に置きます（スキルの cta: が自動で判定）。

やりたいこと やり方
LINE に登録させる 友だち追加 URL を貼るだけ（cta: line）
UTAGE / MyASP などの登録フォーム 埋め込みコードか登録ページ URL を貼る（cta: embed / auto）
配信ツールが無い Google フォームを作って埋め込む（cta: gform）。無料・無制限。回答はスプレッドシートに溜まる
note の販売ページなどへ飛ばす URL を貼る（cta: link）

077. 公開前チェック（スキルの QA と同じ）

  • フォルダに index.html assets/ があるか
  • 画像が全部表示されるか（相対パス assets/img/... になっているか）
  • スマホで見て崩れていないか
  • ボタンの飛び先（LINE / note / フォーム）が正しいか。1回テスト送信する
  • OGP 画像（SNS で共有した時のカード）が出るか。X の Card Validator で確認

088. 消す・止める

Pages の画面 → Settings → General → 一番下の Delete project。URL は即座に無効になる。

099. お金の話

  • Cloudflare Pages: 無料。帯域・アクセス数の上限なし。1ファイル 25MB まで、1サイト 2万ファイルまで、デプロイ月500回まで（個人の LP なら到達しない）
  • 独自ドメイン: 年 1,000〜2,000 円程度（任意）
  • スキルの QA が「総重量 3MB 以内」に収めるので、表示も速い

10困ったとき

症状 原因と直し方
画像が出ない index.html だけ上げている。フォルダごと上げ直す
522 / 開けない 初回デプロイ直後は反映に1〜2分かかる。少し待って再読み込み
更新したのに変わらない ブラウザのキャッシュ。シークレットウィンドウで確認。Deployments で最新が Production になっているか見る
ログインの画面が出ない（メニュー 7） 表示された URL をブラウザで開いて Allow。それでも駄目なら方法 A（ドラッグ&ドロップ）で上げる
Project name が使えない 誰かが使っている名前。末尾に数字を足す（例: mame-kakeibo-2026）
フォームが届かない Pages はフォームを受け取れない。gform / embed / line のどれかにする
独自ドメインが繋がらない DNS 反映待ち（最大 48 時間）。CNAME の値が <名前>.pages.dev になっているか確認
