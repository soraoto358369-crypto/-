# カードの作り方

カード1枚に書くのは1話だけ。あとで1枚だけ読んでも意味が分かるように書く。

## 棚と種類

| 棚 | 種類 | 書くこと |
|---|---|---|
| お客様 | 悩み | 困っている場面。金額、時間、回数があれば残す |
| お客様 | 願い | こうなりたい、という言葉 |
| お客様 | 言い回し | お客様が使った、そのままの言葉 |
| お客様 | 反論 | 買わない理由、迷っている理由 |
| お客様 | 質問 | 実際に聞かれたこと |
| わたし | 経験 | 本人が実際にしたことと、その結果 |
| わたし | 実績 | 確かめられる数字。いつの数字かも書く |
| わたし | 考え方 | 本人の判断の基準。例外があれば一緒に書く |
| わたし | 口調 | 話し方の実例。本人の文をそのまま写す |
| 商品 | 内容 | 何が受け取れるか |
| 商品 | 価格 | 今の値段。いつの値段かも書く |
| 商品 | 条件 | 対象、対象外、期限、返金など |
| 商品 | 事例 | 使った人の変化。名前は伏せる |
| 勝ちパターン | 流れ | 話の順番と、各部分の役割だけ |

## 確かさ

- 原文: 資料の言葉のまま。「」に入れて書く
- まとめ: 資料の内容を短くしたもの
- 予想: 資料には書かれていない推測

お客様の棚は、できるだけ原文で作る。まとめると、お客様の言い方が消えてしまう。

## 追加するときの形

1行に1枚のJSONで書く。

```json
{"棚":"お客様","種類":"悩み","タグ":["見積もり","残業"],"確かさ":"原文","出どころ":"保管庫/2026-11/相談メモ.txt#12行目","本文":"「見積もりを作るだけで毎晩1時間かかっています」"}
```

- 出どころは `台帳の保管先#場所` の形にする。録音なら `#12分30秒`、資料なら `#3ページ` のように書く
- 本人から直接聞いた話は `本人談` で始める。使えるのは「わたし」「商品」の棚だけ
- 資料が複数あるときは `|` で区切る
- タグは2〜3個。お客様が使う言葉を選ぶ

## 勝ちパターンの作り方

反応のよかった投稿や台本を、役割ごとに区切って順番だけ書く。

```text
困りごとの場面 → 自分の失敗 → やり方を3つ → よくある迷いに答える → 次の一歩
```

他の人の公開情報から作るときは、同じ順番が2本以上で確かめられたものだけにする。文章や実績は書かない。

## カードにしないもの

- あいさつ、日程調整、機材の話
- 同じ話の繰り返し（1枚だけ残す）
- 古い価格や終わった条件（今も有効なものと混ぜない）
- 本人の話か他の人の話か分からないもの
