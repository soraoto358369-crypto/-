# ナレッジBOX

作：マツケン社長

「うちの話」を1つの箱に集めて、AIが仕事ごとに必要な分だけ読めるようにする道具です。

## 始め方

パソコンで動くAI（Claude Code または Codex）に、次の文章を送ってください。〔 〕の中は書き換えてください。

```text
ナレッジBOXを使いたいです。この「knowledge-box」フォルダの SKILL.md を読んで、スキルとして導入し、〔デスクトップ〕に箱を作ってください。
```

箱ができたら「受け箱」に資料を1つ入れて、「入れて」と話しかけます。

## 話しかける言葉

- 「入れて」
- 「カードにして」
- 「X投稿のカードを出して」
- 「箱を点検して」

Python 3.9以上が必要です。入っていないときは、AIに「Pythonを入れて」と頼んでください。
